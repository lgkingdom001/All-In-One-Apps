# All In One Apps

A personal all-in-one productivity PWA.

## Planned Features
- Calendar and reminders
- Tasks, goals, and habits
- Notes and journal
- Whiteboard
- Calculator and timer
- QR scanner and generator
- PDF and document tools
- Subscription manager

## Technology
- Frontend: HTML, CSS, JavaScript
- Hosting: GitHub Pages
- Backend and cloud sync: Supabase

## Status
Planning and initial setup.
